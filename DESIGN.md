# Life in Weeks - Design Documentation

## 1. Overview
**Life in Weeks** is a minimalist, "Memento Mori" inspired visualization tool. It transforms the abstract concept of a human lifespan into a tangible grid of time units (weeks, months, or years). The goal is to create a healthy sense of urgency ("urgency, not anxiety") by visually contrasting time lived versus time remaining.

## 2. Visual Identity

### Color Palette
The site uses a strict monochromatic dark theme based on the **Zinc** color scale to convey seriousness and elegance.
*   **Background:** Zinc 950 (`#09090b`) - Deep, void-like black.
*   **Text (Primary):** Zinc 200 (`#e4e4e7`) - High contrast for readability.
*   **Text (Secondary):** Zinc 500 (`#71717a`) - For labels, past events, and metadata.
*   **Accent (Current Time):** Indigo 500 (`#6366f1`) - Used exclusively to highlight the "Now".
*   **Grid (Past):** Zinc 800 (`#27272a`) - Subdued, blending into the background.
*   **Grid (Future):** Zinc 900 (`#18181b`) with Zinc 800 borders - Empty, waiting to be filled.

### Typography
*   **Headings / Data Values:** `Playfair Display` (Serif). Adds a classic, editorial, almost epitaph-like quality to the numbers.
*   **UI / Body / Labels:** `Inter` (Sans-serif). Clean, functional, and legible at small sizes.

## 3. Core Features

### 3.1. Hero & Input (The "Hook")
*   **Layout:** Centered, floating input field.
*   **Interaction:** Users enter their birth date.
*   **Behavior:** The app calculates life data immediately upon date entry using a default 90-year lifespan (switchable to 80).
*   **Default State:** Defaults to a date 25 years in the past to immediately show a populated grid.

### 3.2. Stats Panel (The "Reality Check")
Located at the top of the main dashboard, this panel breaks down the user's remaining time.
*   **AI Insight:** A prominent, "Memento Mori" style quote generated by Google Gemini. It changes based on the user's age and provides stoic, actionable advice (e.g., "You are dying. Live now.").
*   **Progress Bar:** A slim visual bar showing the percentage of life completed.
*   **Life Currency:** A breakdown of remaining time into tangible experiences:
    *   **Summers Left:** (Years remaining).
    *   **Mondays Left:** (Weeks remaining).
    *   **Meals Remaining:** (Weeks * 21).
    *   **Awake Hours:** (Weeks * 112, assuming 8 hours sleep).

### 3.3. The Grid (The "Matrix")
The core visualization component.
*   **Layout:** A vertical list of rows, grouped by Year.
    *   *Left Column:* The Year (e.g., "2024").
    *   *Right Column:* The units for that year (weeks or months).
*   **Tooltips:** Hovering over the Year label displays the count of items in that row.
*   **Unit Nodes:**
    *   **Past:** Dark grey solid blocks.
    *   **Current:** Pulsing Indigo block with a glow effect.
    *   **Future:** Empty, outlined blocks.
*   **Responsiveness:** The grid adapts to screen size.

### 3.4. View Controls (The "Lens")
A control bar sitting immediately above the grid allows manipulation of the data view.
*   **Time Unit Switcher:**
    *   *Years:* Shows blocks representing whole years (Age 0 to 90).
    *   *Months:* Shows rows of 12 blocks per year.
    *   *Weeks:* Shows rows of 52 blocks per year.
*   **Jump To Year:** An input field that instantly scrolls the grid to a specific year and highlights it.
*   **Focus Remaining:** A toggle switch.
    *   *Off:* Shows entire life from birth to death.
    *   *On:* Hides all past years, showing only the current year (from the current date) and the future. Auto-scrolls to the top.

## 4. Technical Architecture

### State Management
*   `birthDate`: Source of truth.
*   `lifespan`: Defaults to 90.
*   `timeUnit`: Controls the granularity of the grid.
*   `focusRemaining`: Filters the rendered array.

### Gemini Integration
*   **Trigger:** Updates whenever the `weeksLived` calculation changes significantly (debounced).
*   **Prompt Engineering:** Instructed to be "ruthless," "punchy," and "stoic." Budget set to 0 for thinking to ensure speed.

### Libraries
*   **Framework:** React 19.
*   **Styling:** Tailwind CSS.
*   **AI:** `@google/genai`.
*   **Fonts:** Google Fonts (Inter, Playfair Display).
